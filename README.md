# cjmoneyway-media-kit
Official CJ Moneyway Executive Media Kit™ landing page and approved press, speaking, podcast, brand, and booking assets.

## Phase 1 frontend

This repository contains the Phase 1 Vite, React, and TypeScript foundation. All public-facing content and media are placeholders pending approval.

### Local setup

```bash
npm install
npm run dev
```

### Checks

```bash
npm run build
npm run lint
```
